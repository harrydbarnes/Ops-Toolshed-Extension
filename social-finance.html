Social Booking Checker

Compare what is in Meta currently to what is booked in Prisma. The report helps break down for you any differences, guiding you on a course to 1:1 matching of bookings.

Platform

Add your report data

Start with a Meta Ads Report so the checker knows which accounts it may read. You can then refresh those accounts through Meta's API.

Before you compare Both sources must cover the same client account(s) and reporting months. CSV files stay in this browser tab; saved Meta API details stay only in this Chrome profile.
1 Meta import Meta Ads Report In Meta Ads Reporting, use the Meta Spend Across Agency template and export at campaign level. The report supplies the Account IDs the API is allowed to refresh. Your CSV must include
  • Account ID
  • Campaign ID
  • Amount spent
  • Month or Reporting starts
Optional reference columns
  • Account name
  • Campaign name
  • Ad set ID
  • Ad set name
  • Campaign budget
  • Campaign budget type
  • Delivery
  • Ad set start
  • Ad set end
Account, campaign, and ad set references are remembered locally. Upload another report when you add a new Meta ad account or want to rebuild that reference. Scope: include every relevant Meta account and campaign for the months being checked. Drag and drop Meta CSV here or choose a file No file selected
2 Prisma export Prisma booking report Use the Prisma CSV that lists placements and their booked values. Your CSV must include
  • Partner account id
  • Partner line id
  • Period
  • PLANNED_AMOUNT or Gross Amount
Optional columns
  • Campaign, Plan or Order name
  • Client name
  • Product name
  • Days in Flight start date
  • Days in Flight end date
  • Placement creator or Owner
These add likely booking matches, client context, date checks, and an owner to contact. Scope: use the same client/accounts and reporting months as the Meta report. Drag and drop Prisma CSV here or choose a file No file selected
