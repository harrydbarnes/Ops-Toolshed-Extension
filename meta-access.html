Meta access

Set up or replace the token used by live campaign checks, monitoring and Social Booking Checker. No report uploads needed.

Obtain a fresh token through your existing Meta access process, with access to the ad accounts you need to check. The existing saved token is never displayed here.

The token is saved in this Chrome profile's local extension storage. Saving it does not validate its permissions; return to Prisma and choose Check Meta to test it. An expired token cannot renew itself.
