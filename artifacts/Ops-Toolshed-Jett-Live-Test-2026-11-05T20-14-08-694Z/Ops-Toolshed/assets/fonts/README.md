# Bundled fonts

Outfit (100–900) and Montserrat (400–700), normal style, from Google Fonts.
Downloaded 22 October 2026. Both use the SIL Open Font License; the original
copyright notices and licence terms are in `outfit-OFL.txt` and
`montserrat-OFL.txt` alongside the fonts.

`fonts.css` retains Google's Unicode subsets and `font-display: swap`. All
original language subsets are included so names and non-English text keep
their existing coverage. Browsers load only subsets needed by visible text.
These fonts apply to extension pages; Prisma content-script fonts are unchanged.

Official stylesheet used to obtain these variable WOFF2 files:
https://fonts.googleapis.com/css2?family=Outfit:wght@100..900&family=Montserrat:wght@400..700&display=swap
