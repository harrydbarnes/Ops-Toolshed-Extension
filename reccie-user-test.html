Google account setup for Reccies

Tracker updates appear under your work Google account in Google Sheets’ edit history. The name you select in Reccies controls which assignments you see.

  1. In Reccies, open Google account for tracker updates and choose Connect my Google account.
  2. Select your work Google account and review Google’s email and Sheets permissions. The service uses those permissions for the Reccie Tracker and its save records.
  3. Return to Reccies and choose Check access. If prompted by Chrome, allow the extension to reach the Google script service. Check that the displayed email is yours.
  4. If the sidebar lists a missing permission, ask Harry to check your writer access and Editor access to both spreadsheets. Then choose Check access again.
  5. Choose Use my Google account for updates if offered. This pauses automatic updates until you turn them back on. Once ready, the panel collapses to Google account connected. Expand it whenever you need to check the account again.

If a background update asks you to verify access after Chrome restarts, reopen Reccies so it can verify the same account again. Use Check access if prompted.
